## Данные:

#### _facenet_ae_3d_data.csv - извлечены с использованием FaceNet + VGGFace2 (актуальная версия ноутбука на kaggle)
(в среднем обучилось 101,2 нейрона из 128 для 10 НКП)

#### _facenet_[mod_decoder]_ae_3d_data.csv - извлечены с использованием последней версии ноутбука fei-face-facenet-features.ipynb
(в среднем обучилось 85,3 нейрона из 128 для 10 НКП)

#### _resnet_ae_3d_data.csv - извлечены с использованием ResNet + Perceptual loss на основе VGG-16 
(ужасно не адаптировано под лица, в среднем обучилось 54,7 нейрона из 128 для 10 НКП)

#### _cvae_3d_data.csv
для признаков, извлеченных с помощью CVAE, получается идеальная картина обучения, но при этом структура связей признаков, образующих мета-признаки, получается довольно примитивной - 1,2 родительских признаков

#### [orig]_vae_3d_data.csv VS vae_3d_data.csv
чем различается? 
результат обучения примерно одинаково хороший

#### [mod]_vae_3d_data.csv - извлечены с использованием последней версии ноутбука fei-face-extraction-with-vae-cvae.ipynb
(в среднем обучилось 120,7 нейрона из 128 для 10 НКП)
(5ый НКП только 65 нейронов)
